## Comment

I think that the scope, file and lines are redundant. We could have just one unified scope.

If the scope is a directory, it would be:
src/

If the scope is the file, it would be:
src/foo.rs

If the scope is only lines, it could be expressed as:
src/foo.rs#L3-7

This way the scope communicates everything and it follows common conventions.
